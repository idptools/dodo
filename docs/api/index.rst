API reference
=============

Every module below gets a page listing its public objects with their docstrings, generated by
autosummary from the source.

Each object is documented exactly **once**, at the place that defines it. The package ``__init__``
files are mostly re-export shims, so documenting them as modules as well produces a duplicate
description for every re-exported name -- 242 of them, when it was tried. The handful of objects
that a package ``__init__`` really does define are listed separately below.

The import to use
-----------------

Nearly everything is re-exported from ``dodo`` itself, and that is the import most code should use:

.. code-block:: python

   import dodo

   report = dodo.rebuild("model.pdb", seed=0)
   dodo.write_pdb(report.models, "out.pdb")

Submodules load lazily (PEP 562), so ``import dodo`` costs about 14 ms and pulls in nothing heavy --
which is what keeps ``dodo --help`` responsive when the optional dependencies would otherwise drag
in torch.
